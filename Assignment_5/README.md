## How to study each question

-   First, understand the problem in simple English.
-   Walk through the example manually.
-   Try to explain the brute-force idea before reading the solution.
-   Study the optimal approach and dry run.
-   Run the code, then change the input and test edge cases.
-   Explain why the time and space complexity have the stated values.

## General note

The code examples use standard Python, C++, and Java. The goal is to
understand the algorithm, not just memorize code.
